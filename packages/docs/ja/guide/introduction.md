# PremiAnnoとは？

PremiAnnoは、Adobe Premiere Pro向けのCEPエクステンションです。タイムラインのカット境界から区間を生成し、各区間にクラスラベルを付与できます。

![PremiAnnoのUI](../../images/overview.png)

## PremiAnnoの目的

編集タイムラインを区間ラベル付きデータへ変換し、分析や学習パイプラインに渡しやすくすることを目的としています。

### ユースケース

- **データセット作成**: 区間ごとのラベル付けデータを作成
- **メディア分析**: 事前定義したクラスで編集区間を整理
- **研究用途**: TOMLとしてエクスポートして下流ツールで処理

## 主な機能

- **カットベーススキャン**: タイムラインカットから区間を生成
- **CSVクラス読み込み**: `index,class` CSVを取り込み
- **ラベル永続化**: プロジェクト/シーケンス単位で保存・復元
- **TOMLエクスポート**: シーケンス情報と区間ラベルを出力

## 基本の流れ

1. Premiere ProでPremiAnnoを開く
2. **Scan Cuts** で区間を生成
3. **Import Classes** でCSVを読み込む
4. 各区間にラベルを割り当てる
5. **Export TOML** で保存する
